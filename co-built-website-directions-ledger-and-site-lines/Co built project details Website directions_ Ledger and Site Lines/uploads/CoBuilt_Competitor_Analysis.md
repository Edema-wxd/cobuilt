# CoBuilt Competitor Analysis (Website & Digital Transparency Focus)

**Prepared for:** Varyn Ltd / CoBuilt Investment Partners — September 2026
**Scope:** Deep-dive on 12 named competitors from the 50-company shortlist, selected as the largest/most digitally active players; remaining 38 grouped by likely segment. Focus is website and investor-transparency positioning, since this feeds the CoBuilt site and Project Passport™.

---

## 1. Landscape at a Glance

Nigerian real estate marketing is dominated by **sales-conversion websites** (property listings, WhatsApp/phone CTAs, agent contact forms) rather than **investor-transparency platforms**. Almost none of the 50 companies reviewed publish live project progress, milestone photos, or a self-serve investor dashboard. Where "portals" exist, they are login gates for existing customers (payment plans, document access) — not public proof-of-progress tools. This is the gap Project Passport™ is built to fill.

## 4. Implications for the CoBuilt Website

1. **Lead with proof, not promises.** Every competitor claims "trust" in copy; none show it in product. Project Passport™'s milestone photos/timeline should be the visible, above-the-fold differentiator.
2. **Match institutional players on compliance, beat them on experience.** UPDC/NMRC/Cappa & D'Alberto set the compliance bar (NGX/SEC filings); none make it pleasant or real-time. CoBuilt can meet the compliance bar and add the UX layer.
3. **Use the PWAN trust gap explicitly (carefully).** The sector's most public scandal is a multi-level, opaque sales model — CoBuilt's website should implicitly (not by name) contrast "verifiable milestones" against "sales-network promises."
4. **Land Republic is the one to watch.** It's the only competitor building toward the same "trust infrastructure" positioning — track its roadmap (portal, land-charting) as the nearest like-for-like benchmark.
5. **Government is quietly modernizing too.** ESHDC's digitization portal shows public-sector digital pressure is rising — a private developer lagging behind a state housing corp is a reputational risk worth avoiding.
